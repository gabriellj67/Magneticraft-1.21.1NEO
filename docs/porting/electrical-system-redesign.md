# 电力体系重设计契约

当前 Forge 1.20.1 电力系统是对 Nova 1.12 设备职责与端口语义的有意重设计，不再把新的电学数值描述为严格原版行为。旧版只用于确认机器角色、单方块方向接口和多方块精确端口；数据包电气配置不能增加、移动或合并这些接口。

## 权威数据与持久化

- `voltage_tiers`、`transformer_profiles` 和 `machine_electrical_profiles` 采用完整快照校验与原子替换。
- 任一文件或交叉引用无效时保留上一份有效快照；首次加载没有有效快照时数据加载失败。
- 重载按现有焦耳重新推导电压，不因电容变化创建或删除能量；电网暂停一刻，并进入可配置的损坏保护期。
- 电气模块、层级物品和长距 `SavedData` 均使用版本化载荷。旧或未知版本安全复位、断网或进入 `MISSING_PROFILE`，不迁移旧电气状态。

## 物理网络

节点遵循：

```text
E = 1/2 C V²
V = sqrt(2E/C)
Q = Ceq * deltaV * (1 - exp(-0.05 / (Rtotal * Ceq)))
A = C/t * 20
W = J/t * 20
```

网络身份是 `PhysicalNodeKey(position, terminalId)`。普通边仅连接同层级端子；保险与断路器使用同方块内部可开闭边；变压器通过 `ElectricalCoupler` 连接两个仍然隔离的连通分量。所有相邻、长距和内部边每刻只处理一次，模拟调用不得改变节点或遥测。

## 域边界和机器角色

电力、FE、热量、液体、气体、物品与物流保持独立。FE 只通过明确转换设备按 `1 J = 1 FE` 交换，并始终先模拟目标接受量。机器角色固定为 `CONSUMER`、`GENERATOR`、`STORAGE`、`CONVERTER` 或 `PASSIVE`；欠压只影响内部缓存充电，配方仍按固定 J/t 消耗。

## 保护、诊断与视觉

- 过流和过压累计统一热应力；保险丝、断路器、线路与机器分别进入熔断、跳闸、烧毁或永久故障状态。
- 电压表提供点测、网络摘要和故障定位，搜索只访问已加载节点且上限 4096。
- GUI、Jade 和客户端颜色只读取服务端同步的不可变显示快照，不参与模拟。
- 新电气设备使用标准 glTF 或兼容 MCX。标准 glTF 不加入私有字段；旁车 `*.manifest.json` 按命名节点或材质映射 Forge tint index，动态开合与故障由命名节点渲染。

## 安全边界

电网不强加载区块，不自动适配任意电压，不允许扳手免费升级线路，不提供万能 FE 接口，也不实现交流相位、三相、接地、爆炸或世界火灾。绝对输入安全边界为层级最大电压的四倍；超过边界时拒绝额外输入并把能量留在源端。
