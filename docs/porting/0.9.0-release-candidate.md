# Magneticraft 0.9.0 玩法对齐候选版

## 结论

`0.9.0` 是 Minecraft 1.20.1、Forge 47.4.20、Java 17 迁移线的玩法对齐候选版。权威迁移矩阵中的历史公开内容均已唯一归属为保留并重命名、重建或明确排除；`0.2.0` 冻结的注册 ID 与持久化边界未在本阶段重新打开。

`1.0.0` 之前仍需完成历史模型、活动部件与发布制品的最终视觉保真收口，但该工作不得改变已经冻结的玩法、注册和保存契约。

## 阶段质量门

以下命令必须在同一候选提交上全部成功：

```powershell
./gradlew.bat compileJava --no-daemon
./gradlew.bat runData --no-daemon
./gradlew.bat runData --no-daemon
./gradlew.bat test --no-daemon
./gradlew.bat runGameTestServer --no-daemon
./gradlew.bat build --no-daemon
./gradlew.bat runServer --no-daemon
./gradlew.bat runClient --no-daemon
```

两次 `runData` 之间必须无资源差异。专服还需对同一世界执行两次完整启动、保存和正常停止；客户端必须到达主菜单且没有缺失模型、纹理、重复注册或客户端/服务端类加载错误。

## 可选模组矩阵

基础安装不得链接可选模组类。运行矩阵覆盖基础、JEI `15.20.0.133`、CraftTweaker `14.0.60`、Tinkers' Construct `3.11.2.166` + Mantle `1.11.97`、Jade `11.13.1+forge` 各自安装，以及四者全组合。JEI 仅作为客户端运行项；其余适用组合同时验证专服加载。
