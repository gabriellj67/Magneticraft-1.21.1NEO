# 1.0.0 视觉与性能验收

## 模型路径

Nova 1.12 的 MCX/glTF 资产以原格式打包。静态方块模型和动态 BER 共用
`LegacyModelLoader` 的重载感知缓存；不再生成 OBJ/MTL 或 8 帧离线动画。

多方块成型后使用 `multiblock_gap` 隐藏并保存结构成员，由控制器 BER 绘制完整
原始场景。解体恢复方块状态及方块实体 NBT，避免结构块与模型重叠。

## 固定边界

- 清单中的 31 个唯一 MCX 与 14 个唯一 glTF 源全部通过解析契约；
- 14 个 glTF 共 511 个节点、354 个引用图元、473 个节点图元实例和 15 个动画；
- 命名节点/子树选择固定电脑、采矿机器人、风力涡轮机、机械臂、电动机和多方块动态部件；
- 蒸汽轮机固定复制 12 片原始叶片；长距离导线仍保持每连接最多 32 段；
- 资源包不包含 GLB、旧离线 OBJ/MTL、逐帧模型 JSON 或 ModelLoader 1.12 类。

## 自动验收

```powershell
./gradlew.bat compileJava test --no-daemon
./gradlew.bat runData --no-daemon
./gradlew.bat runGameTestServer --no-daemon
./gradlew.bat build --no-daemon
```

客户端烟测必须确认无缺失模型、纹理或 legacy scene 错误，并在创造模式世界核对
物品栏、单方块动画、成型多方块完整场景和四向朝向。
