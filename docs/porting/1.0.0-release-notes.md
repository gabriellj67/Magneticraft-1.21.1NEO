# Magneticraft 1.0.0 发行说明

Magneticraft 1.0.0 是面向 Minecraft 1.20.1、Forge 47.4.20 与 Java 17 的完整
玩法迁移版。Nova 1.12 固定快照是行为和视觉来源权威；实现采用现代 Forge
注册、数据生成、能力、网络、持久化和服务端权威模拟契约。

## 兼容边界

- `0.2.0` 执行过一次性破坏式重置。1.0.0 不支持导入 Magneticraft 1.12、
  `0.2.0` 之前的 1.20.1 世界、物品 NBT 或注册 ID；必须创建新世界。
- 从 `0.2.0` 起，注册 ID 和带 `schema_version` 的保存格式已经冻结。1.0.0
  继续读取该基线，后续版本只允许向前兼容扩展或显式数据迁移。
- 不承诺旧 Java API 的二进制兼容，也不提供 BuildCraft 替代层。

## 完成内容

- 电、热、流体、压力、物流和长距离电网；Forge Energy 仅作为 `1 J = 1 FE`
  的适配层。
- 便携电力设备、运输网络、单方块机器、16 类多方块、能源链、矿石/石灰岩/
  油藏生成、电脑、软盘和采矿机器人。
- 英文与简体中文指南、结构说明、配方入口、菜单和诊断提示。
- Nova 1.12 MCX/glTF 的确定性离线转换；静态 OBJ 烘焙模型、8 帧关键动画、
  风机/导线/流体/物流等有界动态渲染。
- 专服权威执行、跨区块安全暂停、持久化连接图和有上限的程序/搜索/渲染预算。

## 可选兼容

基础安装没有强制内容模组依赖。以下集成均为可选，缺失时不会链接其类：

- JEI `15.20.0.133`；
- CraftTweaker `14.0.60`；
- Tinkers' Construct `3.11.2.166` 与其运行时依赖 Mantle `1.11.97`；
- Jade `11.13.1+forge`。

## 明确排除

- 上下坡或垂直传送带；
- `broken/iron/steel/tungsten` 四种没有玩法消费者的历史齿轮；
- 未完成窑炉、内部空气/结构间隙等不可获取占位内容；
- 只有模型而没有完成玩法的历史原型；
- BuildCraft 集成、俄语本地化、跨维度长距离连接、区块强加载；
- 1.12 世界导入、旧 Java API 二进制兼容和不受限制的电脑网络访问。

## 安装要求

- Minecraft 1.20.1
- Forge 47.4.20（兼容声明范围为 Forge 47）
- 64 位 Java 17
