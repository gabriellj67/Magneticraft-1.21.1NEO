# 计算机与采矿机器人

Magneticraft 计算机以服务端权威方式运行有界程序。在编辑器中选择 FORTH、Lisp 或 Shell，输入源代码，并在设备菜单保持打开时上传。程序最多包含 8 KiB UTF-8 源码；每 tick 最多执行 64 条指令、调用四次设备，并保留 2,048 个终端字符。

计算机可以控制红石。采矿机器人还提供移动、旋转、采掘、扫描、库存、能量和采石场命令。所有世界操作都会校验所有者、距离、权限、能量、库存容量与区块加载状态，且绝不强制加载区块。

软盘是唯一的便携程序介质。用户软盘可写；FORTH、Lisp、Shell、BASIC、编辑器和汇编器预置均使用同一个 `floppy_disk` 物品状态。后三种介质只保留为不可执行的历史介质，因为其发布版本实现并未完成。
