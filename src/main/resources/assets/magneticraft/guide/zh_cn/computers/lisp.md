# Lisp 2.0

用括号调用函数，例如 `(print 5)`。使用 `'` 引用值或列表，例如 `'(1 2 3)` 或 `(print 'Hello)`。使用 `(define x 5)` 定义变量，使用 `(defun say-5 () (print 5))` 定义函数；`(env)` 会列出支持的功能。

求值器会限制语法深度、解析节点数、全局变量数、列表长度、调用深度和每 tick 工作量。它支持算术、不可变列表操作、条件、`progn`、`eval`、`define`、`set!` 与 `defun`。非法输入、除零、失控递归和损坏快照都会进入稳定故障状态。

机器人动作必须是顶层表达式：`(front)`、`(back)`、`(left)`、`(right)`、`(up)`、`(down)`、`(mine)` 和 `(scan)`。顶层限制可保证等待中的动作只重试一次，不会重复执行无关副作用。
