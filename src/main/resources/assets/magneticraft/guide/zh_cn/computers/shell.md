# Shell 1.1

Shell 提供 `help`、`ls`、`cd`、`mkdir`、`rm`、`format`、`free`、`fs`、`cat`、`touch`、`write`、`update_disk`、`label` 与 `quarry`。文件系统是保存在 NBT 中的 128 KiB 版本化虚拟软盘，最多 128 个条目，单文件最多 32 KiB。路径无法越过虚拟根目录，也不会访问宿主机文件系统。

`quarry 10` 会让采矿机器人使用可持久化的蛇形游标清理下方 10×10 区域，边长上限为 32 格。到达未加载区块边界时会暂停且不会强制加载；移动、权限、能量或库存校验失败时会安全停止。

历史 `pastebin` 与 `update` 命令会被明确拒绝，因为程序没有出站网络权限。这也阻止程序下载或执行不可信的宿主机内容。
