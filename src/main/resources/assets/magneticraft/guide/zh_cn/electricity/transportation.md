# 电力运输

电缆只连接相邻、同层级且侧面兼容的端子。层级在合成物品时确定，放置后不能用扳手免费改变。破坏电缆或设备会移除运行时边；重新加载后根据局部持久状态重建，稳定拓扑不会每 tick 重建。

潜行使用铜线卷选择第一个端点，再对兼容的第二个端点使用。内置距离为：

| 层级 | 连接器 | 电线杆 |
|---|---:|---:|
| 低压 | 8 格 | 16 格 |
| 中压 | 16 格 | 32 格 |
| 高压 | 32 格 | 64 格 |

不同层级、端口类型或维度会被拒绝，且不消耗线卷。长距离线路的电阻按实际几何距离放大。

标准和重型保护规格分别为 8 C/t 与 16 C/t。持续过载会累积热应力：保险丝熔断、断路器跳闸，而无保护电缆最终变为烧毁且断开的电缆。红石信号会强制断路器断开；取消信号不会清除手动跳闸。维修故障机器前，所有端子必须低于标称电压的 95%。

远端区块卸载时传输暂停。连接不会强加载区块，任一端点被破坏时会先清理持久化链路，之后不再传输。
