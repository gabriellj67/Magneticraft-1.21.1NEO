# Electricity Fundamentals

Voltage is electrical potential, current is the flow during a network step, and resistance limits that flow. Power is reported in watts and network energy in joules. The voltmeter displays all three instantaneous readings for the selected face.

Connections are directional where a machine declares a specific port. A visually adjacent cable is not enough if that side is disabled; use the wrench or machine configuration interaction to change allowed sides.

The server owns all network mutation and conservation checks. Client displays are snapshots and cannot inject energy or create links.
