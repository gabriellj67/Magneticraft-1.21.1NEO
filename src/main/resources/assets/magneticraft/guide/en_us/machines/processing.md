# Processing Machines

Processing machines consume declared items, fluids, heat, or electricity and advance only while their output can be accepted. Progress and inventories persist across saves.

Concrete recipes are data driven. The guide identifies each recipe family; JEI displays inputs, outputs, duration, temperature, pressure mode, and energy values when installed, while CraftTweaker can add recipes without becoming a required dependency.

The section covers early crushing and sluicing through grinder, sieve, press, electric furnace, gasification, steam, and petroleum processing.
