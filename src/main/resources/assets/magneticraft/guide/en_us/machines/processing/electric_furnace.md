# Electric Furnace

The electric furnace uses native electrical energy to run vanilla smelting recipes. The top input and output automation rules are distinct, and direct external FE capability is intentionally absent.

Processing speed is quantized from the electrical node's stored J. Progress persists while output is blocked, and the working visual has a short grace period before becoming idle.

Use JEI for smelting inputs and the machine page for exact slot and electrical-side rules.
