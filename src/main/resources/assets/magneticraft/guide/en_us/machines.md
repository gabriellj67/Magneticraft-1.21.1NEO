# Machines

Single-block machines cover early processing, storage, power conversion, transport endpoints, and utilities. Their in-game pages are generated from the same definitions used by menus and capabilities, so slot roles and physical ports are authoritative.

Recipe-backed machines expose a recipe family. Install JEI for browsing concrete inputs and outputs, or inspect the data recipes directly; CraftTweaker can extend the same families when installed.

See [Generators](machines/generators.md), [Processing](machines/processing.md), [Transport](machines/transport.md), and [Utilities](machines/utilities.md).
