# Magneticraft Guide

Magneticraft is organized around separate electricity, heat, fluid, pressure, and item-logistics networks. Machines exchange state only through their declared ports; Forge Energy is an adapter at exactly `1 J = 1 FE`.

Start with [Getting Started](getting_started.md), then use the machine, multiblock, world-generation, electricity, heat, and computer sections. In-game machine pages identify automation sides and recipe families; JEI can display the concrete data recipes when installed.

All simulation and tool actions are server authoritative. Unloaded chunks pause networks and structures instead of being force-loaded.
